# Abartılı Damga ve İmza Makinesi

Bu proje, insanlık tarihinin en ciddi, en ağır başlı ve en gereksiz bürokratik protokolüdür.

Herhangi bir şeyi (bir selam, bir hesap, bir varoluş sorgusu) onaylamak için tam olarak **13 damga** ve **47 imza** gereklidir. Daha azı yasadışıdır.

## Nasıl Çalışır?

```bash
python damga_imza.py
```

Program sizden onaylanacak metni ister. Sonra aşağıdaki prosedürü başlatır:

1. Metni 7 kez okur (her okumada "anlaşıldı" der)
2. Rastgele damgalar basar (ONAYLANDI, REDDEDİLDİ, BEKLEMEDE, GİZLİ)
3. İmzalar toplar (her imza 0.3 saniye sürer, çünkü acele iş şeytandandır)
4. Sonunda resmi damga vurur

## Uyarı

Bu program gerçekten çalışır. Gerçekten damga basar. Gerçekten imza toplar. 

Hiçbir şeyi hızlandırmayın. Acele edenler kuyruğa girer.
